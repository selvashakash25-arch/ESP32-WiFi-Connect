# ESP32 WiFi Connect

## Author
SELVASH

## Description
This project connects the ESP32 to a WiFi network and displays the assigned IP address through the Serial Monitor.

## Components
- ESP32 DevKit

## Working
1. ESP32 starts.
2. ESP32 connects to the Wokwi WiFi network.
3. The connection status is displayed.
4. The assigned IP address is displayed in the Serial Monitor.
